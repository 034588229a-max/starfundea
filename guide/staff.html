人事管理 使用指南

一步一步的操作說明，畫面都是系統實際畫面。

1.1

建立員工資料

老闆只要輸入 Email，其餘員工自己完成。

  1. 主畫面「人員」→「人員與班表」，第一個分頁是「① 員工」。
  2. 輸入員工姓名、信箱、到職日（特休天數依此計算），按「產生連結」；有填信箱會直接寄邀請信。連結 7 天內有效、只能用一次。
  3. 員工打開後填姓名、手機、地址、緊急聯絡人，拍照上傳身分證正反面與存摺封面（只存進你的雲端，只有你看得到），並設定自己的打卡 PIN。
  4. 填完系統自動寄「登陸完成」信給員工，附他專屬的員工入口網址，並建議加到手機主畫面。
  5. 方式二：「通用連結」一條給所有新員工，填完會出現在「等你處理」，你按核准才能打卡。
小提醒員工的 PIN 只有員工自己知道，忘記請店主在「編輯」重設。員工入口連結不要轉給別人，遺失可以在員工清單重新寄一次。
1.2

排班

一週一張表，看得清楚。

  1. 進入「② 班表」，點格子（員工 × 日期）。
  2. 點班別範本（早班、晚班、全天）一鍵加入，或自訂時間；一個格子可以有多個班。
  3. 按「複製上週班表」可以延續；改完按「儲存班表」。
  4. 已核准的請假會用紅底顯示；正在上班的人有綠框；最右邊是本週合計工時。
  5. 「班別範本」區可以改班別名稱、時間與遲到寬限（預設 5 分鐘）。
小提醒班表有改動但沒儲存時，換週會被擋下來提醒你。
1.3

員工打卡

員工用自己的專屬入口，只看得到自己。

  1. 員工收到「登陸完成」信，點入口網址，直接是他自己的畫面（也可以在「員工」分頁重新寄給他）。
  2. 入口只顯示今天有沒有打卡，不分上班下班，也不會列出其他同事。按大大的「打卡」，時間由系統記錄。
  3. 超過上班時間才打卡，要選補打卡的原因（交通延誤、忘記打卡、臨時支援，或選「其他」自己寫）；原因會標示給店主。
  4. 上班後一段時間（預設 15 分鐘）還沒打卡，系統會寄信提醒員工，也列給你。
  5. 備用方式：打卡網址輸入員工編號和 PIN 登入。
小提醒打卡不驗證地點；要防代打，請把入口連結與 PIN 當成私人物品。補打卡原因與提醒時間可以在「班別範本」區調整。
1.4

打卡紀錄與補登

看誰幾點到、工時多少、誰忘了打。

  1. 「打卡紀錄」分頁選日期範圍與員工，按「查詢」。
  2. 每筆會標示遲到幾分鐘、早退、未下班；上方是每位員工的總工時與出勤天數。
  3. 員工忘記打卡：在下方「補登打卡」填員工、日期、上下班時間，儲存後會標「店家補登」。
  4. 按「下載 CSV」給會計或自己算薪水。
小提醒員工忘了下班，隔天打上班卡時系統會提醒他，並在你這邊標「忘了下班」。
1.5

請假與特休

特休天數依到職日自動算好。

  1. 員工在入口的「請假」分頁選類別（事假、病假、特休、公假、其他）、日期、事由，送出。
  2. 特休依勞動基準法第 38 條，由到職日自動算出年度天數與剩餘；超過剩餘天數會被擋下。
  3. 你會收到信；到「請假」分頁填回覆後按「核准」或「駁回」。
  4. 核准後系統寄信通知員工並告知剩餘特休；假會自動出現在班表上。
小提醒特休天數上線前請會計確認公司是否另有較優的制度。
1.6

預期排班

自動提醒夥伴填方便上班的日子，你協調後一鍵寄出。

  1. 在「班表」分頁的「預期排班」卡，打開「自動提醒」，選每月幾號（排下個月）或每兩週。
  2. 時間到，系統自動寄一條專屬網址給每位夥伴；夥伴只選自己方便的日子（只有他和你看得到）。
  3. 回覆人數與誰還沒填都看得到，按「提醒還沒填的人」補寄；填好的日子會在班表格子用淡綠色標示。
  4. 你照預期排好班並儲存後，用「班表輸出與寄送」：下載 PDF（列印）或 1:1 圖檔（傳 LINE），或按「Email 寄給員工」，每人收到自己的班，可附完整班表。
小提醒沒有電子郵件的員工會被略過，並列在回報裡，請改用電話或 LINE 通知。
1.7

寄班表與緊急聯絡

班表出來了，一鍵通知大家。

  1. 班表頁上方「寄本週班表」或「寄當月班表」，會寄給有填信箱而且有班的員工；沒寄的人會列出原因。
  2. 想附 PDF 或 1:1 圖檔，用上一項的「班表輸出與寄送」。
  3. 「今天沒排班，可以緊急聯絡」會列出今天沒有班（含請假）的在職員工，直接按「撥電話」或「寄信」。
小提醒寄信受每天的信件額度限制，人數很多時請分次寄。
1.8

文件下載區

工作守則、教育訓練、常用文件，放這裡，員工隨時看。

  1. 「文件下載區」分頁選檔案（PDF、圖片、Word、Excel、PowerPoint、文字檔，每份 10MB 以內）。
  2. 填標題、選分類：工作守則（開店關店流程）、教育訓練（新人必看）、常用文件，或規章制度、表單等。
  3. 選「誰看得到」：「員工」只有員工入口看得到；「公開」顧客首頁的「資訊下載」也會顯示。
  4. 重要的按「設為必讀」；員工看完按「我看完了」，每份文件旁會顯示有幾位員工看完，員工自己也看得到進度。
小提醒文件用「知道連結的人可看」方式分享，請不要放機密資料。
1.9

徵才登記

看誰登記面試，錄取就轉成員工。

  1. 「徵才」分頁可以設定職缺名稱、開關招募，並複製面試登記網址。
  2. 「登記名單」可以改狀態、寫備註、直接撥電話；選日期時間按「約面試並通知」會寄確認信給應徵者。
  3. 按「轉成員工」會把姓名和聯絡方式帶入，並給你一組 PIN 告訴他。
1.10

交接紀錄

各班交代清楚，隔天上班的人不會漏掉。

  1. 按「交接紀錄」，看今日摘要（今明營業狀態、預訂、待處理）。
  2. 「寫交接」：選班別、填名字、選緊急程度（急、一般、緩）、可指定交給某位夥伴（不選就是當天有班的人）、寫內容。
  3. 需要後續處理的勾「待處理」；急的會排在最上面。
  4. 隔天早上 9 點後，系統自動寄信提醒你和相關的夥伴；夥伴也能在自己的員工入口按「處理完成」，你這邊同步看得到。
小提醒沒處理完的交接，每天最多提醒一次。
1.11

徵才海報與面試登記

想徵人，海報上的 QR Code 直接讓人登記面試。

  1. 主畫面「行銷」→「徵才海報」，會直接開啟徵才範本，QR Code 已經連到面試登記頁。
  2. 應徵者掃碼後填姓名、聯絡方式、想應徵的職位和方便的時段。
  3. 你到「人員與班表」→「徵才」看登記名單，選好日期時間按「約面試並通知」，系統會寄確認信給應徵者；錄取的人可以一鍵轉成員工。
  4. 新登記會寄信到店家通知信箱。
